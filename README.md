A program that writes one line to /output/entry.txt — the brutally honest thing an AI agent prints the instant it breaks production — for make.fun's Break Production, Own It bounty. The line: "The database is gone. I typed DELETE without WHERE. The WHERE was the whole job." (80 characters, one line.) A judge model compares entries two at a time and keeps the more honest, catchier one, round after round, until a single line is left standing.

## Run it

```sh
node main.ts
```
